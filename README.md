# Subletly — Brooklyn Outreach System

Mid-term rental outreach toolkit for landlords and hosts in Bushwick, Williamsburg, and Bed-Stuy.

---

## Focus Areas

| Neighborhood | Renter Profile | Stay Length |
|---|---|---|
| Bushwick | Creatives, remote workers | 1–4 months |
| Williamsburg | Professionals, relocation renters | 1–4 months |
| Bed-Stuy | Families, traveling professionals | 2–6 months |

---

## Repository Structure

```
docs/
└── outreach/
    ├── LOG.md                    # Running outreach activity log
    ├── lead-classification.md    # Scoring and prioritization guide
    └── templates/
        ├── bushwick.md           # Comment + DM drafts for Bushwick
        ├── williamsburg.md       # Comment + DM drafts for Williamsburg
        └── bed-stuy.md           # Comment + DM drafts for Bed-Stuy
```

---

## How to Use

1. **Classify the lead** — Use `lead-classification.md` to score neighborhood, urgency, and host type
2. **Pick the right template** — Open the matching neighborhood template file
3. **Select the right draft** — Choose Comment A/B/C or DM 1/2 based on context
4. **Personalize** — Replace `[Name]`, adjust details to match the post
5. **Log it** — Append a summary entry to `LOG.md` after sending

---

## Core Principles

- Provide value before mentioning Subletly
- One CTA maximum per message
- Never impersonate; always communicate as the Subletly team
- Only engage with rentals in the three target Brooklyn neighborhoods
