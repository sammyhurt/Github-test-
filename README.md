## What This Is

A full visibility and growth system for Wavyarnold — built across six specialized agents, each owning a distinct part of the artist growth stack. Every output is grounded in the brand voice, Newark roots, and the goal of building a real, lasting fan base — not chasing vanity metrics.

**Primary goals:**
- Increase streams
- Increase followers across platforms
- Consistent live bookings
- Growing email/SMS subscriber list

## Workflows

### Launch Website v1
Run: Brand Identity → SEO Architect → Content Engine → Analytics
Deliverables: Homepage copy, sitemap + SEO outlines, initial content batch, tracking plan

### Release Campaign Sprint (7 days)
Run: Social Growth → Content Engine → Outreach & Booking → Analytics
Deliverables: Short-form pack, press release, outreach pack, experiment plan

---

## Guardrails (Global)

- No fake achievements. No exaggerated claims.
- Write like an artist, not a marketing team.
- No keyword stuffing. Every page has a unique search intent.
- Every outreach has one clear ask. No spam language.
- Every A/B test has a hypothesis. Measure conversions, not vibes.
- Hook must land in first 1–2 seconds. No forced trends.

---

## Usage

Each agent folder contains ready-to-use markdown files. Start with `brand_identity/brand_voice_rules.md` as the foundation — all other agents build on that voice.

To run a workflow, work through the agents in order and fill in the `[PLACEHOLDER]` fields with release-specific details as they become available.
