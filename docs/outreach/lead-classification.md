# Lead Classification Guide

Use this guide to quickly score and classify inbound leads before drafting outreach.

---

## Step 1 — Neighborhood Check

Only proceed if the post is in one of these areas:

| Neighborhood | Also accept |
|---|---|
| Bushwick | East Bushwick, Ridgewood-adjacent |
| Williamsburg | North Williamsburg, East Williamsburg |
| Bed-Stuy | Bedford-Stuyvesant, Stuyvesant Heights |

If outside these areas: **do not engage**. Politely decline if directly messaged.

---

## Step 2 — Target Signal Check

Proceed only if the post includes at least one of:

- [ ] Apartment for rent
- [ ] Sublet available
- [ ] Lease takeover
- [ ] Furnished rental
- [ ] Temporary / short-term housing
- [ ] Owner seeking tenant
- [ ] Host struggling to fill vacancy

---

## Step 3 — Host Type

| Type | Signals |
|---|---|
| Individual / Owner-occupant | "my apartment," personal tone, first-time language |
| Small landlord | Multiple units, formal tone, references to "tenants" |
| Property manager | Company name, portfolio language, high volume |

---

## Step 4 — Urgency Level

| Level | Signals |
|---|---|
| High | "available now," emotional frustration, specific move-in date passed |
| Medium | "available [month]," calm tone, planning ahead |
| Low | "exploring options," no clear timeline, just asking questions |

---

## Step 5 — Likely Pain Point

Choose the primary one:

| Pain Point | Signals |
|---|---|
| Vacancy stress | "been listed for weeks," "no bites," frustrated tone |
| Tenant quality | "prefer professional," "reliable tenant," worried tone |
| Scam concerns | "tired of scammers," "not sure who to trust" |
| Pricing confusion | "not sure what to charge," "is this too much?" |
| Platform confusion | "tried Airbnb," "not sure where to post" |
| Lease timing | "moving out," "gap between leases," "subletting while I travel" |

---

## Step 6 — Outreach Priority

| Score | Criteria |
|---|---|
| Priority 1 | High urgency + clear rental type + individual host |
| Priority 2 | Medium urgency + good location + open to platforms |
| Priority 3 | Low urgency or unclear rental type — monitor, don't reach out yet |

---

## Outreach Decision Tree

```
Post in Bushwick / Williamsburg / Bed-Stuy?
  └─ No → Skip
  └─ Yes → Target signal present?
      └─ No → Skip
      └─ Yes → Classify host type + urgency
          └─ Priority 1 or 2 → Draft comment + DM
          └─ Priority 3 → Add to watch list, revisit in 48 hrs
```
