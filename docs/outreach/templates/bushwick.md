## Platform Do/Don't Notes

### Facebook Groups
- **Do:** Reply to comments publicly first before sliding into DMs
- **Do:** Use casual, local tone — not corporate
- **Don't:** Drop links in the first comment (gets flagged/removed)
- **Don't:** Post the same comment on multiple listings in one day

### Craigslist
- **Do:** Email directly (no comment function)
- **Do:** Keep subject line neutral: "Question about your Bushwick listing"
- **Don't:** Mention competitors by name
- **Don't:** Use formatted lists — plain text only

### Reddit (r/nyc, r/AskNYC, r/brooklyn)
- **Do:** Lead with genuine advice, earn trust before mentioning Subletly
- **Do:** Disclose affiliation naturally: "I work with a platform called Subletly..."
- **Don't:** Post promotional content in rule-strict subreddits
- **Don't:** DM unsolicited — comment first, let them reach out
