# Wavyarnold — Outreach Templates

**Rule:** Every outreach has one clear ask. No spam language. Short, direct, human.

---

| Category | Examples | Primary Ask |
|----------|----------|-------------|

| Local press | Newark/NJ music blogs, alt-weeklies, local newspapers | Feature or interview |

| Podcast hosts | Music culture, indie artist, Newark/NJ podcasts | Guest appearance |

## Follow-Up Sequence

### Follow-Up #1 (7 days after first outreach, if no response)
```
Hey [Name] — just following up on my note from last week.

Happy to share more if that would help, or to connect at a better time.

[Name]
```

### Follow-Up #2 (14 days after first outreach, if still no response)
```
Hi [Name] —

Last follow-up from me on this. If the timing's off or it's not the right fit, totally understood.

If you'd ever want to revisit, I'm at [email/contact].

[Name]
```

*After 2 follow-ups with no response: move to next contact. Do not send a third.*

## CRM Tracking Fields

| Field | Description |
|-------|-------------|
| Contact Name | Individual contact person |
| Organization | Venue, blog, playlist name |
| Category | Venue / Press / Curator / Promoter / Collab |
| Location | City, state |
| Outreach Date | Date of first contact |
| Channel | Email / DM / In-person |
| Status | Not contacted / Sent / Responded / In progress / Closed |
| Ask | What was requested (booking, feature, playlist add) |
| Response | Summary of reply or "No response" |
| Follow-up Date | When to send follow-up #1 |
| Notes | Anything relevant for next contact |
